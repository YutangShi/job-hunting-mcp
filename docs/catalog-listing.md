# mcpservers.org 目錄上架檢查表

## 目的與範圍

本文件記錄將來提交至 [mcpservers.org](https://mcpservers.org/zh-TW/) 的準備工作。它是第三方 MCP 伺服器目錄的提交清單，不代表 MCP 協定認證、官方 MCP Registry 發佈、ChatGPT／Claude 客戶端核准，亦不代表 104 或 Cake 授權本專案使用其資料。

資料查核日期：2026-10-25。目錄表單與審核方案可能變動，正式提交前必須重新確認。

## 目錄提交頁列出的欄位

| 表單欄位 | 必要性 | 本專案值／狀態 |
|---|---|---|
| 伺服器名稱 | 必填 | 待定。候選名稱：`Taiwan Jobs MCP`；正式名稱須在公開文件與服務 metadata 一致。 |
| 分類 | 必填 | 待定；提交時依表單當時提供的分類選單選擇最合適類別，首頁目前有「搜尋」分類。 |
| 簡短描述 | 必填 | 候選：`透過對話搜尋台灣公開職缺，依條件篩選並開啟來源平台原始職缺。` 需清楚標示 V1 目前只有 104，資料來自 104 網站公開頁面使用的 JSON 端點。 |
| 原始碼儲存庫、網站或文件 | 必填 | 待定；目前工作目錄不是 Git repository，需先建立公開且可維護的原始碼或文件連結。 |
| 官方 MCP Registry 名稱 | 選填 | 尚無；只有先發布至官方 MCP Registry 後才填入正式 identifier。 |
| 支援遠端連線 | 必填選項 | 目前不可宣稱支援；部署 HTTPS MCP endpoint 並通過外部連線驗證後再勾選。 |
| 聯繫信箱 | 必填 | 待定；由維護者指定可持續維護的公開支援信箱，不使用臆造或無人監看的地址。 |
| 提交方案 | 必選 | 預設規劃使用免費提交；查核當日表單顯示免費審核最長 2 週，另有一次性付費加速選項。費用與時間可能調整；付費需另經維護者明確決定。 |

表單目前未在提交頁列出明確的 endpoint 技術規範、隱私政策欄位、最低 uptime 或協定測試清單。以下「上架前技術檢查」是本專案為可靠發佈設定的準備條件，不宣稱是目錄的正式審核規則。

## 本專案上架前技術檢查

- [ ] 公開文件與 metadata 描述同一個服務，工具名稱、功能和來源狀態一致。
- [ ] 公開 HTTPS endpoint 可由預期客戶端網路連線，MCP initialize、tools/list 及代表性唯讀工具呼叫成功。
- [ ] 明確說明遠端 transport、endpoint、認證設定、ChatGPT／Claude 連線步驟、權限要求和常見錯誤。
- [ ] 若 endpoint 或來源不可用，文件和目錄資訊不宣稱服務可用；有維護者可執行的停用／撤下方式。
- [ ] 公開隱私說明涵蓋查詢內容、回傳資料、跨境 LLM 客戶端處理、日誌、快取、留存及刪除政策。
- [ ] 清楚揭露 V1 透過 104 網站 JSON 端點及 curl-impersonate 相容 client 取得搜尋結果，並說明端點可能變動。
- [ ] 來源名稱、職缺連結與資料取得時間完整；Cake 未啟用時不出現在可用來源或搜尋結果中。
- [ ] 明確說明來源端點可能變更或拒絕請求，並記錄 403、429、驗證頁、timeout 及 schema drift 的處置方式。
- [ ] 職缺內容被當作不可信外部資料，不會改變工具權限或觸發未授權資料存取。
- [ ] 聯絡信箱、原始碼／文件連結與分類選擇已由維護者檢查。
- [ ] 維護者審閱最終表單內容；未明確授權前不得提交或付款。

## 上架與其他發佈管道的區別

- **mcpservers.org**：第三方目錄；需依其提交表單提供 metadata 並經其審核。
- **Official MCP Registry**：獨立發佈管道；目錄表單只將其 identifier 列為選填資訊，不表示目錄收錄會替服務註冊官方 Registry。
- **ChatGPT／Claude**：各自的客戶端連線、方案資格、認證與上架流程；目錄收錄不保證特定客戶端一定可安裝或會核准服務。
- **104／Cake**：資料來源平台；任何目錄或客戶端收錄都不代表平台背書，也不會保證網頁端點持續可用。
