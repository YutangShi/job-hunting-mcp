# Proposal

## Why

求職者通常是依職務條件找工作，不應先知道某筆職缺刊登在哪個平台才能開始搜尋。搜尋工具應自動查詢所有已授權且啟用的來源，再在每筆結果清楚標出資料來源與原始連結。

## What Changes

- 新增來源透明的跨平台唯讀職缺搜尋與詳情查詢行為。
- 搜尋輸入不要求使用者指定 Cake 或 104；服務會查詢全部已授權且啟用的來源。
- 每筆職缺結果包含來源名稱、來源識別碼、原始職缺連結與資料時間；詳情查詢透過搜尋結果附帶的來源限定 `job_ref` 路由，不要求使用者另選來源。
- 定義部分來源失敗時回傳可用結果並揭露來源狀態；所有來源皆失敗時回傳明確錯誤。
- 保持來源授權閘門：未授權來源不查詢、不顯示為可用；不使用未公開端點或防爬繞過方式。

## Capabilities

### New Capabilities

- `job-search`: 提供使用者不必選擇資料平台的職缺搜尋、來源標示、部分失敗回報與來源限定職缺詳情查詢。

### Modified Capabilities

無。

## Impact

- MCP tools：搜尋工具不暴露來源選擇欄位；詳情工具接收來源限定的 `job_ref`。
- Source adapters：對已啟用、已授權來源扇出查詢並正規化結果；來源錯誤彼此隔離。
- 領域模型：搜尋結果增加來源標記、來源職缺 ID、原始連結、資料時間與可供詳情查詢的 reference。
- 文件：更新 README 與架構說明，清楚呈現使用者不必指定來源。
- 前置條件：Cake 與 104 各自的資料存取與展示授權仍須先確認；無授權來源維持停用。
